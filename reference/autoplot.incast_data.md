# Plot surveillance data

Plot observed counts by series. If revisions are present, use the latest
reported value for each date.

## Usage

``` r
# S3 method for class 'incast_data'
autoplot(object, ...)
```

## Arguments

- object:

  An `incast_data` from
  [`check_data`](https://accidda.github.io/incast/reference/check_data.md).

- ...:

  Ignored.

## Value

A ggplot object.
